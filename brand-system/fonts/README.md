# Fonts

`Inter-Regular.ttf`, `Inter-SemiBold.ttf`, `Inter-Bold.ttf`: Inter by The Inter Project Authors (https://github.com/rsms/inter), licensed under the SIL Open Font License 1.1 (full text in `OFL.txt`). For renderers that need a local font file (captions, motion graphics).

The brand sheet's own fonts (Bricolage Grotesque, JetBrains Mono, Instrument Serif) load from Google Fonts, also OFL. Excalifont loads with Excalidraw from esm.sh.
