# Radar

Run `python3 research/radar/radar.py collect` from the repo root once a day (or as a scheduled task): it pulls what is catching on from GitHub (via `gh`), Reddit and Hacker News RSS, Product Hunt, YouTube (via `yt-dlp`) and, if you set `TWITTER_AUTH_TOKEN` and `TWITTER_CT0` in `.env`, X (via `twitter-cli`), and writes one JSON file to `~/.agent-reach/radar/YYYY-MM-DD.json`. Claude then ranks that file with `RUBRIC.md` and writes the day's digest to `research/radar/YYYY-MM-DD.md`, followed by the outliers pass (`research/outliers/outliers.py collect`, after you copy `research/outliers/watchlist.example.json` to `watchlist.json`). Change the subreddits and search queries in `config.json` under `"radar"` (`subreddits`, `youtube_queries`, `x_queries`); links already on your free-files site (`site/library.json`, optional) and links in `seen.json` are marked so they are not suggested twice. It needs Python with `feedparser`, plus `gh` and `yt-dlp` on your PATH; a source that fails is noted and the rest still run. `python3 research/radar/radar.py selftest` checks the parser offline.
